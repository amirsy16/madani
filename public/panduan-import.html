Import Data Donatur

ℹ️
Informasi:
Gunakan fitur import untuk menambahkan banyak data donatur sekaligus (tidak perlu satu-satu). Kode donatur akan dibuat otomatis dengan format DN25XXXX.

📝 Langkah-langkah Import

  1. Buka menu Donatur di menu atas
  2. Tekan tombol Import Donatur (tombol berwarna hijau)
  3. Tekan Download Template untuk mengunduh contoh tabel Excel
  4. Buka file Excel yang diunduh, lalu isi data sesuai petunjuk di bawah
  5. Simpan file Excel yang sudah diisi
  6. Tekan tombol Pilih File dan pilih file Excel yang tadi diisi
  7. Tekan Import dan tunggu sampai proses selesai

Import Data Donasi

ℹ️
Informasi:
Sebelum memasukkan data donasi, pastikan data Donatur sudah ada di sistem. Nomor transaksi akan dibuat otomatis oleh sistem.

📝 Langkah-langkah Import

  1. Buka menu Donasi di menu atas
  2. Tekan tombol Import Donasi (tombol berwarna hijau)
  3. Tekan Download Template untuk mengunduh contoh tabel Excel
  4. Buka file Excel yang diunduh, lalu isi data sesuai petunjuk di bawah
  5. Simpan file Excel yang sudah diisi
  6. Tekan tombol Pilih File dan pilih file Excel yang tadi diisi
  7. Tekan Import dan tunggu sampai proses selesai

Import Program Penyaluran

ℹ️
Informasi:
Pastikan saldo dana mencukupi sebelum memasukkan data penyaluran. Khusus untuk Dana Zakat, wajib mengisi kolom Asnaf (jenis mustahik).

📝 Langkah-langkah Import

  1. Buka menu Penyaluran Dana di menu atas
  2. Tekan tombol Import Penyaluran (tombol berwarna hijau)
  3. Tekan Download Template untuk mengunduh contoh tabel Excel
  4. Buka file Excel yang diunduh, lalu isi data sesuai petunjuk di bawah
  5. Simpan file Excel yang sudah diisi

Tips & Troubleshooting

💡 Tips Penting Agar Import Berhasil

✅
Tip #1: Selalu Unduh Template Terlebih Dahulu
Template Excel sudah berisi contoh data yang benar. Gunakan sebagai panduan agar tidak salah format.
✅
Tip #2: Siapkan Data Induk Dulu
Sebelum import, pastikan semua data induk sudah lengkap (seperti: Daftar Pekerjaan, Jenis Donasi, Metode Pembayaran, dan lain-lain).
✅
Tip #3: Import Sedikit Demi Sedikit
Untuk data yang banyak, import bertahap saja (50-100 baris per file). Ini lebih mudah jika ada kesalahan.
✅
Tip #4: Urutan yang Benar
1. Import Donatur terlebih dahulu
2. Pastikan ada saldo di menu Sumber Dana
3. Baru import Donasi
4. Terakhir import Program Penyaluran

❓ Pertanyaan yang Sering Diajukan (FAQ)

T: Kenapa data saya tidak masuk setelah import?

J: Periksa hal-hal berikut:

  • Kolom yang wajib diisi sudah terisi semua
  • Format data sudah benar (tanggal, angka, dan lain-lain)
  • Data yang dihubungkan sudah ada (contoh: kode donatur, jenis donasi)
  • Tidak ada data yang sama/duplikat (nomor HP, email)

T: Muncul pesan "Donatur tidak ditemukan" saat import donasi?

J: Pastikan kode donatur yang Anda ketik benar-benar sudah ada di sistem. Buka menu Donatur untuk melihat daftar kode yang ada.

T: Muncul pesan "Jenis donasi tidak ditemukan"?

J: Nama jenis donasi harus ditulis sama persis dengan yang ada di sistem. Perhatikan huruf besar/kecil dan spasi. Lihat daftar di panduan ini.

Q: Bagaimana cara menulis tanggal yang benar?

A: Ketik tanggal seperti biasa di Excel:

Format Tanggal: DD/MM/YYYY
Contoh: 17/12/2025 (artinya 17 Desember 2025)

Cara yang benar:

  • ✅ Ketik langsung: 17/12/2025 di kolom Excel
  • ✅ Atau ketik: 17-12-2025 (Excel akan ubah sendiri jadi 17/12/2025)
  • ✅ Biarkan Excel yang atur formatnya, jangan diubah-ubah

⚠️ Yang perlu dihindari:

  • ❌ Jangan ubah format sel menjadi Text
  • ❌ Jangan ketik tanda petik (') di depan tanggal
  • ❌ Pastikan formatnya DD/MM/YYYY (bukan MM/DD/YYYY seperti format Amerika)

💡 Tips Mudah: Unduh template, Excel sudah diatur formatnya dengan benar. Tinggal ketik tanggal seperti biasa saja!

T: Muncul pesan "Jumlah melebihi saldo tersedia"?

J: Saldo dana tidak mencukupi. Pastikan sudah ada data donasi masuk sebelum melakukan penyaluran, atau kurangi jumlah yang disalurkan.

T: Apakah bisa import ribuan data sekaligus?

J: Sebaiknya maksimal 100-200 baris per file saja untuk menghindari proses yang terlalu lama. Untuk data lebih banyak, pisah menjadi beberapa file.

🔧 Syarat File Excel yang Benar

  • ✅ Gunakan file dengan format .xlsx atau .xls
  • ✅ Halaman pertama Excel yang akan dibaca sistem
  • ✅ Baris pertama adalah nama kolom (jangan dihapus)
  • ✅ Data mulai dari baris kedua ke bawah
  • ✅ Jangan ada baris kosong di tengah-tengah data
  • ✅ Jangan pakai perhitungan otomatis yang rumit
  • ❌ Jangan gabung-gabungkan kotak di area data
