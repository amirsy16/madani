🏠 Pertanyaan Umum
Apa itu Sistem Madani? +

Sistem Madani adalah platform digital terintegrasi yang dirancang khusus untuk mengelola seluruh proses penghimpunan dan penyaluran dana Zakat, Infaq, Sedekah, serta Dana Sosial Keagamaan Lainnya (DSKL) secara profesional, transparan, dan akuntabel.

Sistem ini dibangun dengan teknologi Laravel Filament v3 untuk memberikan pengalaman pengguna terbaik dengan antarmuka yang intuitif dan responsif.

Siapa saja yang bisa menggunakan sistem ini? +

Sistem ini digunakan oleh berbagai role pengguna:

  • Super Admin - Akses penuh ke semua fitur termasuk pengaturan sistem
  • Operator - Mengelola input donasi dan update data donatur
  • Finance - Melihat laporan keuangan dan mengelola penyaluran dana
  • Fundraiser - Melihat performa pribadi dan riwayat donasi
Bagaimana cara mendapatkan akun akses? +

Akun akses diberikan oleh Administrator sistem. Hubungi admin atau IT support Anda untuk mendapatkan:

  • Email login
  • Password awal
  • Role/permission yang sesuai

Setelah menerima kredensial, Anda wajib mengganti password pada login pertama untuk keamanan.

🔐 Login & Keamanan Akun
Saya lupa password, bagaimana cara reset? +

Untuk reset password:

  1. Klik link "Forgot Password" di halaman login (jika tersedia)
  2. Masukkan email yang terdaftar di sistem
  3. Cek inbox email untuk link reset password
  4. Jika link tidak tersedia, hubungi Administrator untuk reset manual
Kenapa saya tidak bisa login? +

Beberapa penyebab umum:

  • Email/password salah - Periksa kembali kredensial Anda
  • Akun belum aktif - Hubungi admin untuk aktivasi
  • Caps Lock aktif - Password bersifat case-sensitive
  • Browser cache - Coba clear cache atau gunakan incognito mode
  • Koneksi internet - Pastikan internet stabil
Bagaimana cara membuat password yang aman? +

Tips membuat password yang kuat:

  • Minimal 8 karakter
  • Kombinasi huruf BESAR dan kecil
  • Sertakan angka (0-9)
  • Tambahkan simbol (!@#$%^&*)
  • Jangan gunakan informasi pribadi (tanggal lahir, nama, dll)
  • Jangan gunakan password yang sama untuk akun lain

Contoh password kuat: M@dani2025!Secure

💰 Manajemen Donasi
Bagaimana cara input donasi baru? +

Langkah input donasi:

  1. Buka menu Program → Donasi
  2. Klik tombol "Buat Baru"
  3. Isi form dengan lengkap (4 section):
    • Informasi Donatur - Pilih/tambah donatur, jenis donasi, tanggal
    • Detail Donasi - Jumlah/nilai, kategori (jika ada)
    • Metode Pembayaran - Cara bayar, fundraiser, bukti transfer
    • Status Konfirmasi - Pending/Verified/Rejected
  4. Klik "Simpan"
Apa perbedaan Zakat, Infaq Terikat, dan Infaq Tidak Terikat? +

Zakat: Dana wajib yang harus disalurkan ke 8 asnaf (fakir, miskin, amil, mualaf, riqab, gharim, fisabilillah, ibnu sabil)

Infaq Terikat: Donasi sukarela dengan tujuan spesifik yang ditentukan donatur (contoh: untuk pembangunan masjid, beasiswa, dll)

Infaq Tidak Terikat: Donasi sukarela tanpa ketentuan khusus, bisa disalurkan untuk program apapun sesuai kebutuhan

Bagaimana cara membuat donasi anonim? +

Saat input donasi, aktifkan toggle "Sembunyikan Nama Donatur" di section Informasi Donatur.

Donasi akan tercatat sebagai "Hamba Allah" di sistem dan laporan, tetapi data donatur tetap tersimpan untuk keperluan internal administrasi.

Bagaimana cara input donasi barang? +

Untuk donasi barang:

  1. Pilih Jenis Donasi yang memiliki flag "Donasi Barang"
  2. Field "Jumlah Donasi (Uang)" akan disembunyikan
  3. Isi field "Deskripsi Barang" - jelaskan detail barang (jenis, jumlah, kondisi)
  4. Isi field "Perkiraan Nilai Barang" - estimasi nilai dalam Rupiah

Contoh: "Beras 10 kg kualitas premium + Minyak goreng 5 liter"

👥 Manajemen Donatur
Apa itu kode donatur dan bagaimana formatnya? +

Kode donatur adalah ID unik yang otomatis digenerate sistem dengan format:

DN + YY + XXXX

Contoh: DN250001 (Donatur pertama tahun 2025)

  • DN = Prefix tetap untuk Donatur
  • 25 = Tahun pendaftaran (2025)
  • 0001 = Nomor urut donatur di tahun tersebut
Bagaimana sistem segmentasi donatur bekerja? +

Sistem otomatis mengelompokkan donatur berdasarkan total kontribusi:

  • 👑 PLATINUM - Total donasi > Rp 10.000.000
  • 🥇 GOLD - Total donasi Rp 5.000.000 - Rp 10.000.000
  • 🥈 SILVER - Total donasi Rp 1.000.000 - Rp 5.000.000
  • 🥉 BRONZE - Total donasi Rp 500.000 - Rp 1.000.000
  • ⭐ REGULAR - Total donasi < Rp 500.000

Segmentasi ini membantu strategi retention dan komunikasi dengan donatur.

Bagaimana cara menggabungkan data donatur duplikat? +

Sistem memiliki fitur anti-duplikasi otomatis:

  • Saat input nama, sistem akan cek similarity (kemiripan >= 80%)
  • Jika ditemukan nama mirip, muncul notifikasi warning
  • Nomor HP unik - tidak boleh duplikat

Jika sudah terlanjur duplikat, hubungi Admin untuk merge data secara manual.

📄 Invoice & Kwitansi
Bagaimana cara kirim invoice ke donatur? +

Setelah donasi terverifikasi:

  1. Buka menu Program → Donasi
  2. Cari donasi yang sudah verified
  3. Klik tombol "Kirim Invoice"
  4. Pilih metode pengiriman:
    • 📱 WhatsApp - Kirim otomatis ke nomor HP donatur
    • ⬇️ Download - Download PDF untuk dicetak/dikirim manual
  5. Tambahkan catatan (opsional)
  6. Klik "Kirim"
Apa saja yang tercantum di invoice? +

Invoice donasi berisi:

  • Nomor Invoice - ID unik transaksi
  • Tanggal - Tanggal donasi
  • Data Donatur - Nama, alamat, HP, email
  • Jenis Donasi - Zakat/Infaq/Sedekah/DSKL/CSR
  • Jumlah - Nominal dalam Rupiah (terbilang)
  • Metode Pembayaran - Transfer/Tunai/dll
  • Tanda Tangan Digital - Cap dan TTD pengurus
Bagaimana cara melihat riwayat pengiriman invoice? +

Di tabel donasi, klik tombol "Riwayat Invoice" untuk melihat:

  • Tanggal pengiriman
  • Metode (WhatsApp/Download)
  • Status (Pending/Terkirim/Tersampaikan/Gagal)
  • Nomor tujuan (HP/Email)
  • Error message (jika gagal)
🔄 Penyaluran Dana & Program
Bagaimana cara membuat program penyaluran dana? +

Gunakan Wizard 3 Step di menu Program → Penyaluran Dana:

  1. Step 1: Informasi Program
    • Nama program (contoh: "Santunan Anak Yatim Ramadan 2025")
    • Tanggal penyaluran
    • Lokasi penyaluran
    • Keterangan detail program
  2. Step 2: Sumber & Alokasi Dana
    • Pilih sumber dana (Zakat/Infaq/DSKL/CSR)
    • Lihat saldo tersedia real-time
    • Input jumlah dana (otomatis validasi tidak boleh > saldo)
    • Pilih Asnaf (jika dana zakat)
    • Pilih bidang program
  3. Step 3: Detail Penerima
    • Tipe: Individu atau Lembaga
    • Nama penerima
    • Jumlah penerima manfaat
    • Upload bukti penyaluran
Apa itu 8 Asnaf dan kapan harus dipilih? +

8 Asnaf adalah golongan penerima zakat yang wajib dipilih saat menyalurkan Dana Zakat:

  1. Fakir - Orang yang tidak memiliki harta dan tenaga untuk memenuhi kebutuhan
  2. Miskin - Orang yang memiliki harta/penghasilan kurang dari kebutuhan
  3. Amil - Pengelola zakat (Hak Amil)
  4. Mualaf - Orang yang baru masuk Islam atau lemah imannya
  5. Riqab - Budak atau hamba sahaya (konteks modern: korban human trafficking)
  6. Gharim - Orang yang terlilit hutang untuk kebutuhan mendesak
  7. Fisabilillah - Untuk kepentingan agama Islam
  8. Ibnu Sabil - Musafir yang kehabisan bekal dalam perjalanan

Penting: Field Asnaf hanya muncul untuk Dana Zakat. Untuk Infaq/Sedekah/DSKL, tidak perlu pilih Asnaf.

Kenapa saya tidak bisa input jumlah penyaluran tertentu? +

Sistem memiliki validasi otomatis:

  • Jumlah penyaluran tidak boleh melebihi saldo tersedia
  • Saldo tersedia = Total Penerimaan - Penyaluran Sebelumnya - Hak Amil
  • Cek widget "Saldo Tersedia" yang muncul setelah pilih sumber dana

Contoh: Jika saldo Dana Zakat Rp 50 juta, Anda tidak bisa input penyaluran Rp 60 juta.

Apa itu Penyaluran Langsung? +

Penyaluran Langsung adalah dana yang disalurkan tanpa melalui proses penghimpunan terlebih dahulu.

Contoh kasus: Ada donatur yang ingin langsung menyalurkan bantuan ke penerima tertentu tanpa dikelola lembaga.

Dana ini masuk ke Dana Umum dan tidak diperhitungkan dalam statistik penghimpunan utama.

💼 Sistem Hak Amil
Apa itu Hak Amil dan bagaimana perhitungannya? +

Hak Amil adalah bagian dana yang boleh digunakan untuk operasional lembaga pengelola zakat/donasi.

Perhitungan Otomatis:

  • Setiap sumber dana punya persentase hak amil sendiri (setting di Pengaturan Hak Amil)
  • Contoh: Dana Zakat = 12.5%, Dana Infaq = 15%, Dana DSKL = 10%
  • Rumus: Hak Amil = Total Penerimaan × Persentase Hak Amil

Contoh: Total Dana Zakat Rp 100 juta × 12.5% = Hak Amil Rp 12,5 juta

Bagaimana cara menggunakan Hak Amil? +

Langkah penggunaan Hak Amil:

  1. Buka menu Laporan & Keuangan → Penggunaan Hak Amil
  2. Klik "Buat Baru"
  3. Pilih Jenis Penggunaan (Gaji, Operasional, Marketing, dll)
  4. Input Jumlah (tidak boleh > sisa hak amil)
  5. Upload Bukti (nota/invoice/kwitansi)
  6. Tambahkan Keterangan
  7. Klik "Simpan"

Sistem otomatis mengurangi saldo hak amil yang tersedia.

Bagaimana cara monitoring Hak Amil? +

Lihat Widget Hak Amil Overview di Dashboard yang menampilkan:

  • Total Hak Amil - Bagian yang berhak diterima
  • Sudah Digunakan - Total penggunaan sampai saat ini
  • Sisa Tersedia - Saldo yang bisa digunakan
  • Persentase Penggunaan - Progress bar visual

Filter berdasarkan periode untuk analisis lebih detail.

Kenapa persentase Hak Amil berbeda-beda? +

Persentase disesuaikan dengan regulasi dan kebijakan lembaga:

  • Dana Zakat - Maksimal 12.5% (sesuai ketentuan syariah)
  • Dana Infaq/Sedekah - Bisa lebih fleksibel (10-20%)
  • Dana CSR/DSKL - Sesuai kesepakatan dengan donatur

Setting ini diatur oleh Super Admin di menu Pengaturan Hak Amil.

🤝 Fundraiser & Performa
Bagaimana cara menambahkan fundraiser baru? +

Langkah menambahkan fundraiser:

  1. Buka menu Program → Fundraiser
  2. Klik "Buat Baru"
  3. Isi data:
    • Nama Fundraiser
    • Nomor Identitas (KTP/SIM)
    • Nomor HP
    • Alamat
    • User Akun (opsional - jika punya akun login)
    • Status Aktif (toggle ON)
  4. Klik "Simpan"
Bagaimana cara assign donasi ke fundraiser? +

Saat input donasi, di section Metode Pembayaran:

  • Ada field "Fundraiser" (dropdown)
  • Pilih nama fundraiser yang menghimpun donasi tersebut
  • Jika donasi tidak melalui fundraiser, biarkan kosong

Donasi yang di-assign akan otomatis masuk ke perhitungan performa fundraiser.

Bagaimana melihat performa fundraiser? +

Lihat di Widget Fundraiser Performance di Dashboard:

  • Ranking - Urutan berdasarkan total kontribusi
  • Total Kontribusi - Jumlah dana yang berhasil dihimpun
  • Jumlah Donatur - Berapa donatur unik yang berdonasi melalui fundraiser
  • Rata-rata Donasi - Average per transaksi

Filter berdasarkan periode untuk evaluasi bulanan/tahunan.

Apakah fundraiser bisa login ke sistem? +

Ya, jika diberi akun user oleh Admin:

  • Saat tambah/edit fundraiser, hubungkan dengan User Akun
  • User tersebut akan dapat role "Fundraiser"
  • Fundraiser bisa login dan melihat:
    • Dashboard personal
    • Performa pribadi
    • Riwayat donasi yang dihimpun
    • Ranking dibanding fundraiser lain

Catatan: Fundraiser tidak bisa input donasi, hanya melihat performa.

📊 Import & Export Data
Bagaimana cara import data donasi dari Excel? +

Langkah import donasi:

  1. Buka menu Program → Donasi
  2. Klik tombol "Import" di atas tabel
  3. Download Template Excel (jika belum punya)
  4. Isi data sesuai format template:
    • Kolom wajib: Tanggal, Nama Donatur, Jenis Donasi, Jumlah
    • Kolom opsional: HP, Email, Metode Bayar, Fundraiser, Catatan
  5. Upload file Excel yang sudah diisi
  6. Klik "Proses Import"
  7. Sistem akan validasi dan tampilkan preview
  8. Review data, lalu klik "Konfirmasi Import"

Tips: Import maksimal 500 baris per file untuk performa optimal.

Bagaimana cara export data ke Excel? +

Langkah export data:

  1. Buka modul yang ingin diexport (Donasi/Donatur/Penyaluran/dll)
  2. Gunakan filter untuk memilih data spesifik (opsional)
  3. Centang data yang ingin diexport (atau select all)
  4. Klik tombol dropdown (⋮) di atas tabel
  5. Pilih "Export"
  6. File Excel akan terdownload otomatis ke folder Downloads

Format Export: .xlsx dengan semua kolom yang tampil di tabel.

Kenapa import gagal atau ada data yang error? +

Penyebab umum error import:

  • Format tanggal salah - Gunakan format DD/MM/YYYY atau YYYY-MM-DD
  • Jenis Donasi tidak ditemukan - Pastikan nama jenis donasi sesuai dengan data di sistem
  • Donatur duplikat - Nomor HP sudah terdaftar dengan nama berbeda
  • Jumlah format salah - Gunakan angka tanpa titik/koma (contoh: 100000 bukan 100.000)
  • Kolom wajib kosong - Periksa semua field yang required

Sistem akan tampilkan detail error per baris untuk memudahkan perbaikan.

Apakah bisa import donatur secara bulk? +

Ya! Sama seperti import donasi:

  • Buka menu Program → Donatur
  • Klik "Import"
  • Download template, isi data donatur
  • Upload dan proses import

Penting: Sistem otomatis cek duplikasi berdasarkan nomor HP dan similarity nama ≥80%.

📈 Dashboard & Analytics
Bagaimana cara filter statistik berdasarkan periode? +

Di widget Ringkasan Statistik Utama, gunakan dropdown filter periode:

  • Keseluruhan - Semua data dari awal
  • Tahun Ini - Januari s/d sekarang tahun berjalan
  • Bulan Ini - Tanggal 1 s/d hari ini bulan berjalan
  • Custom Range - Pilih tanggal mulai dan selesai sendiri

Semua angka statistik akan update otomatis sesuai periode yang dipilih.

Apa itu segmentasi RFM di Top Donatur? +

RFM Analysis adalah metode segmentasi donatur berdasarkan:

  • Recency (R) - Kapan terakhir donasi (semakin baru semakin baik)
  • Frequency (F) - Seberapa sering donasi (semakin sering semakin loyal)
  • Monetary (M) - Total nilai donasi (semakin besar semakin valuable)

Hasil Segmentasi:

  • 👑 Platinum - Donatur premium (R tinggi + F tinggi + M tinggi)
  • 🥇 Gold - Donatur loyal (kombinasi 2 dari 3 tinggi)
  • 🥈 Silver - Donatur potensial (1 metrik tinggi)
  • 🥉 Bronze - Donatur baru/jarang
Bagaimana cara melihat detail donasi per donatur? +

Ada 2 cara:

Cara 1 - Dari Widget Top Donatur:

  • Klik pada angka Total Donasi di tabel
  • Modal akan terbuka dengan daftar lengkap semua donasi
  • Lihat tanggal, jenis donasi, nominal, metode bayar

Cara 2 - Dari Halaman Donatur:

  • Buka Program → Donatur
  • Klik nama donatur untuk lihat detail
  • Scroll ke tab "Donasi"
  • Lihat tabel lengkap riwayat donasi donatur tersebut
Apa itu Insight Strategis di dashboard? +

Insight Strategis adalah rekomendasi otomatis dari sistem berdasarkan analisis data:

  • 🚨 Prioritas Tinggi (Merah) - Alert untuk donatur Platinum yang tidak donasi 3 bulan → perlu follow-up retention
  • ⚠️ Perhatian (Kuning) - Donatur Silver konsisten → potensi upgrade ke Gold dengan pendekatan personal
  • 📊 Informasi (Biru) - Trend positif, donatur baru, peningkatan frekuensi, dll

Insight ini membantu strategi fundraising dan donor management.

⚙️ Troubleshooting Teknis
Kenapa sistem loading lambat? +

Penyebab dan solusi:

  • Koneksi internet lambat - Cek kecepatan internet (minimal 2 Mbps)
  • Browser cache penuh - Clear cache browser (Ctrl+Shift+Del)
  • Banyak tab terbuka - Tutup tab yang tidak perlu
  • Server overload - Coba akses di waktu yang berbeda
  • Browser outdated - Update ke versi terbaru (Chrome/Firefox/Edge)
  • Banyak filter aktif - Reset filter yang tidak perlu
Data yang saya input hilang, kenapa? +

Kemungkinan penyebab:

  • Belum klik "Simpan" - Pastikan selalu klik tombol Simpan
  • Session timeout - Login kembali jika sudah lama idle (>30 menit)
  • Koneksi terputus - Pastikan internet stabil saat input
  • Browser crash - Sistem tidak auto-save, harus manual save
  • Validasi error - Cek notifikasi error di form

Tips: Untuk data penting, salin ke notepad dulu sebelum input ke sistem.

Kenapa invoice WhatsApp gagal terkirim? +

Penyebab umum dan solusi:

  • Nomor HP tidak valid - Pastikan format 628xxx (tanpa +, spasi, atau -)
  • Donatur tidak punya HP - Gunakan opsi "Download" lalu kirim manual
  • Nomor tidak terdaftar di WhatsApp - Verifikasi nomor donatur
  • WhatsApp Business API limit - Tunggu beberapa menit lalu coba lagi

Cek status pengiriman di menu Riwayat Invoice untuk detail error.

Bagaimana cara backup data? +

Backup data dilakukan dengan 2 cara:

Manual Export (User):

  • Export data per modul (Donasi, Donatur, Penyaluran) ke Excel
  • Simpan file di storage aman (Google Drive/OneDrive)
  • Lakukan export minimal 1x seminggu

Database Backup (Admin/IT):

  • Hubungi Administrator untuk backup database lengkap
  • Backup otomatis dilakukan sistem setiap hari (jika dikonfigurasi)
  • File backup .sql disimpan di server
Saya tidak bisa akses menu tertentu, kenapa? +

Ini karena Role & Permission Anda:

  • Setiap user memiliki role tertentu (Admin/Operator/Finance/Fundraiser)
  • Setiap role punya permission berbeda untuk akses menu
  • Contoh: Fundraiser tidak bisa input donasi, hanya lihat performa

Jika Anda butuh akses tambahan, hubungi Super Admin untuk request permission.

Bagaimana cara report bug atau request fitur? +

Untuk melaporkan masalah atau request fitur baru:

  1. Klik tombol WhatsApp di halaman ini
  2. Jelaskan masalah dengan detail:
    • Apa yang terjadi?
    • Kapan terjadi?
    • Di menu/halaman mana?
    • Langkah untuk reproduksi
    • Screenshot (jika ada)
  3. Tim support akan respond maksimal 1x24 jam

Tips: Sertakan screenshot atau screen recording untuk mempercepat troubleshooting.

🔒 Keamanan & Privasi Data
Apakah data donatur aman di sistem ini? +

Ya! Sistem dilengkapi dengan multiple layer security:

  • HTTPS/SSL Encryption - Semua data terenkripsi saat transmisi
  • Database Encryption - Data sensitif terenkripsi di database
  • Role-Based Access Control - User hanya bisa akses sesuai permission
  • Audit Trail - Semua aktivitas tercatat (siapa, kapan, apa)
  • Session Management - Auto logout setelah idle 30 menit
  • Password Hashing - Password disimpan dalam bentuk hash, tidak plain text
Siapa saja yang bisa melihat data donatur? +

Akses data donatur dibatasi berdasarkan role:

  • Super Admin - Akses penuh semua data
  • Operator - Bisa lihat, tambah, edit data donatur
  • Finance - Bisa lihat data donatur (read-only)
  • Fundraiser - Hanya bisa lihat donatur yang ia himpun

Data sensitif seperti nomor HP dan email tidak bisa diexport oleh Fundraiser.

Bagaimana jika ada donatur yang minta data dihapus? +

Sesuai kebijakan privasi dan regulasi:

  • Donatur berhak request penghapusan data pribadi
  • Hubungi Super Admin untuk proses penghapusan
  • Admin akan:
    • Verifikasi identitas donatur
    • Backup data untuk arsip legal (jika diperlukan)
    • Hapus atau anonimkan data di sistem

Catatan: Data transaksi donasi tetap tersimpan untuk audit, tetapi identitas pribadi dianonimkan.

Apakah sistem ini compliance dengan regulasi? +

Sistem dirancang sesuai dengan:

  • UU Zakat - Pengelolaan dan pelaporan zakat sesuai BAZNAS
  • Standar Akuntansi - PSAK 109 untuk akuntansi zakat dan infaq/sedekah
  • Privacy & Data Protection - Perlindungan data pribadi donatur
  • Financial Reporting - Transparansi laporan keuangan

Sistem menghasilkan laporan yang bisa diaudit eksternal.
